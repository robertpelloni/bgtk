# MEMORY

- **Codebase Origins:** Started as Bobgui/GTK codebase, heavily reliant on standard C-based GObject architecture.
- **Target Architecture:** Modern, multi-paradigm C++ combined with a parallel, comprehensive Go port.
- **Design Preferences:** Clean, well-structured, easy to use, well-named, and highly documented.
- **Current Observation:** The project has undergone a massive renaming from `gtk` and `bobgui` to `bobtk`. Pathing issues or build files (e.g., meson.build, Makefiles) may require further refinement if `bobtk` replacements broke regex or internal tooling.
- **System Tray and Server Process Supervisor:** Added cross-platform system tray integration (`SystemTrayIcon` in C++, `SystemTray` in Go) with dynamic context menus and background daemon lifecycle tracking (`ServerProcessController` / `ServerManager`).
- **Consolidated Dashboard Paradigm:** All features across the 6 pillars are centralized into a single-page consolidated view without fragmented subpages, featuring prominent cards, tooltips, and server shutdown controls.
- **Go Core Pillar Implementation:** `QuantumScheduler` handles concurrent pooled background execution (`CoWork` pattern), `ReflectContext` provides dynamic `Value` binding and observable properties, and `EntityManager` manages ECS component relationships.
- **Go Visual Pillar Qt6 Parity:** Implemented `BoxLayout` (`QHBoxLayout`, `QVBoxLayout`), `GridLayout` (`QGridLayout`), `StackedLayout` (`QStackedLayout`), and reactive widget controls (`Button`, `Label`, `LineEdit`, `ProgressBar`).
- **Go Network & Media Pillars:** Network pillar hosts `BroadwayGateway` (remote HTML5 canvas streaming) and `WebSocketHub` (JSON-RPC transport). Media pillar hosts `AudioGraph` (JUCE-like DSP audio processors) and `MidiBus` (MIDI 2.0 Universal MIDI Packets).
- **JUCE Integration & Analysis:** `JUCE_ANALYSIS.md` maps JUCE component hierarchies and audio graphs into Bobtk. The Visual pillar now features `Component` with relative coordinate trees, bounds recalculation, and recursive repaint pipelines, coupled with `Timer` periodic dispatching in Core.
- **Go 6-Pillar Architecture Parity:** All 6 pillars (Core, Media, Network, System, Tools, Visual) now have concrete Go implementations with unit test suites and centralized dashboard integration.
- **Native C/C++ Runtime Bridge:** `NativeBridge` in `go/bobtk/core/bridge.go` provides handle mapping, resource management, and event routing between the Go runtime and C/C++ GObject handles.
- **Ultimate++ NTL Submodule Primitives:** The Go Core pillar includes `Vector` (cache-coherent fast dynamic array), `HeapPool` (slab arena allocator), `Map` (ordered indexed map), and `StateSerializer` (JSON state persistence).
- **Qt6 Event & Action Architecture:** The Go framework now implements `Signal` (thread-safe slot connection/disconnection and emission), `Action` (`QAction` parity with reactive `Triggered`/`Toggled` signals), and `KeyEvent` (`QKeyEvent` parity with modifier bitmasks).
- **FileSystem & Settings:** `FileSystemWatcher` (in System pillar) monitors file mutation events and `Settings` (in Core pillar) provides thread-safe key-value configuration storage.
- **Canvas & 2D Vector Graphics:** `GraphicsContext` (in Visual pillar) handles drawing operations, color states, clipping rects, and vector `Path` tracing, integrated into the `Component` paint pipeline.
- **Animation & State Machine:** `PropertyAnimation` provides value interpolation over time and `StateMachine` enables event-driven state transitions in the Core pillar.
- **Network Access & State Sync:** `NetworkAccessManager` executes/logs HTTP transfers, while `SyncEngine` synchronizes remote cursor movements and binary state deltas across connected peers.
- **Server Telemetry & Keyboard Accelerators:** The single-page dashboard now incorporates `ServerTelemetry` metrics (CPU, memory, uptime, request counters), `LogSubscriber` dynamic log streaming, and an interactive global keyboard accelerator dispatcher (`RegisterShortcut` / `HandleKeyPress`) for unified system operations.
- **Tools Pillar Execution Tracing:** `PerformanceProfiler` in `go/bobtk/tools/tools_pillar.go` provides fine-grained execution tracing through `StartSpan`, `EndSpan`, `GetSpans`, and `FormatTraceReport` (Sysprof parity).
- **Qt6 Widget Set Parity:** In addition to `Button`, `Label`, `LineEdit`, `ProgressBar`, `Slider`, and `CheckBox`, the Visual pillar provides `ComboBox` (item list dropdown selector), `RadioButton` (mutually exclusive group selector), `TabWidget` (titled multi-page tabbed container), and `Splitter` (partitioned resizable container).
- **JUCE DSP Parity:** Media pillar provides `SineOscillatorProcessor` (ToneGeneratorAudioProcessor parity), `LowPassFilterProcessor` (IIRFilter parity), and `DelayProcessor` (circular buffer delay line) within `AudioGraph`.
- **MIDI 2.0 Packets:** `go/bobtk/media/midi.go` provides UMP builders for `NewNoteOn`, `NewNoteOff`, and `NewControlChange` with 16-bit/32-bit high resolution.
- **WebSocket Cluster Broadcasting:** `WebSocketHub` in `go/bobtk/network/websocket.go` manages connected `WebSocketSession` peers with non-blocking per-client channels and broadcast dispatching.
- **CoWork ParallelFor:** `QuantumScheduler` in `go/bobtk/core/scheduler.go` provides index-partitioned `ParallelFor` concurrent loops with completion barriers.
- **Server Process Control:** `ServerManager` in `go/bobtk/system/server_manager.go` provides comprehensive daemon lifecycle management including `StartServer`, `StopServer`, `RestartServer`, and `GetServer`.
- **Environment Diagnostics:** `tools/check_health.sh` provides non-destructive pre-flight environment, toolchain, submodule, and test diagnostics, invokable directly or via `tools/run_dashboard.sh --check-health`.
- **Sysprof Subproject Wrap:** Corrected `gtk=false` in `meson.build` default_options for `libsysprof_capture_dep` and defined the `sysprof` feature option in `meson_options.txt`.
- **Clipboard Subsystem:** `SystemPillar` provides thread-safe clipboard abstraction (`go/bobtk/system/clipboard.go`) with change notifications and clearing operations.
- **Instruction Governance:** Synchronized `CLAUDE.md`, `GEMINI.md`, `GPT.md`, and `copilot-instructions.md` with explicit 6-pillar framework directives, single-page dashboard standards, system tray & server supervisor controls, and pre-flight diagnostics tooling.
- **Binary Stream Serialization:** `StateSerializer` in `go/bobtk/core/serializer.go` provides `BinaryPack` and `BinaryUnpack` for high-throughput fixed-size binary streaming (`upp::Stream` and `QDataStream` parity).
- **RingBuffer FIFO Queue:** `RingBuffer[T]` in `go/bobtk/core/ring_buffer.go` provides a thread-safe circular FIFO buffer with non-blocking try-push/pop, timed blocking push/pop, and channel-like graceful shutdown (`juce::AbstractFifo` and U++ stream parity).
- **Fast User-Space Concurrency Primitives:** `FastMutex` and `ReadWriteSpinLock` in `go/bobtk/core/sync.go` provide low-latency user-space spin-locks avoiding OS context switching for high-frequency GUI event loops (`upp::SpinLock` and `juce::SpinLock`/`ReadWriteLock` parity).
- **Splitter Fallback Safeguard:** `Splitter.Layout` in `go/bobtk/visual/widgets.go` safely protects against division by zero if empty or zero-weight partition slices are supplied, defaulting `totalSize = len(s.items)`.
- **Extended HTTP Client:** `NetworkAccessManager` in `go/bobtk/network/http_client.go` supports PUT and DELETE HTTP verbs alongside GET and POST, and includes default header state management (`SetHeader`/`GetHeader`).
- **MIDI 2.0 Modulation Packets:** `go/bobtk/media/midi.go` provides UMP packet builders for `NewPitchBend` (32-bit wheel value) and `NewPolyPressure` (32-bit per-note aftertouch).
- **Ellipse Vector Drawing:** `GraphicsContext` in `go/bobtk/visual/graphics.go` provides `DrawEllipse` and `FillEllipse` (`QPainter::drawEllipse` and `juce::Graphics::drawEllipse`/`fillEllipse` parity).
- **Clipboard MIME Storage:** `Clipboard` in `go/bobtk/system/clipboard.go` supports arbitrary binary and MIME payloads (`SetData`/`GetData`) and empty-state queries (`HasText`).
- **Profiler Category Analytics:** `PerformanceProfiler` in `go/bobtk/tools/tools_pillar.go` provides category-based span queries (`GetSpansByCategory`), mean latency calculation (`AverageDuration`), and state reset (`Clear`).
- **Platform Awareness in Bridge:** `NativeBridge` in `go/bobtk/core/bridge.go` queries target OS/arch (`TargetOS`/`TargetArch`) and allows dynamic mode transitions (`SetMode`).
- **Widget Enablement State:** `WidgetBase` in `go/bobtk/visual/widgets.go` supports `SetEnabled` and `IsEnabled` (`QWidget::setEnabled`/`isEnabled` parity) with automatic event suppression on disabled controls.
- **Meson Build Syntax Corrections:** Repaired multiple historical syntax artifacts in `meson.build` including duplicate `project()` calls, missing bracket closures on `check_headers`, unterminated `check_functions` loops, and unclosed `cairo_backends` loops.
- **Meson Options Harmonization:** Consolidate build option definitions into `meson.options` and eliminated duplicate `meson_options.txt` to prevent Meson configuration file collision.
- **AudioBuffer Operations:** `AudioBuffer` in `go/bobtk/media/audio_graph.go` supports `Clear()`, `CopyFrom()`, and `GetMagnitude()` (`juce::AudioBuffer<float>` parity).
- **Wrap File Cleanup:** Removed corrupted duplicate git metadata appended to `subprojects/gdk-pixbuf.wrap` and `subprojects/pango.wrap`.
- **Widget Visibility State:** `WidgetBase` in `go/bobtk/visual/widgets.go` supports `SetVisible` and `IsVisible` (`QWidget::setVisible`/`isVisible` parity).
- **Wrap File Cleanup (Batch 2):** Cleaned duplicate configuration blocks in `subprojects/fribidi.wrap` and `subprojects/libpng.wrap`.
- **Label Text Accessors:** `Label` in `go/bobtk/visual/widgets.go` provides thread-safe `SetText` and `GetText` (`QLabel::setText`/`text` parity).
- **Button Text Accessors:** `Button` in `go/bobtk/visual/widgets.go` provides thread-safe `SetText` and `GetText` (`QPushButton::setText`/`text` parity).
- **WorkPool Task Dispatcher:** `WorkPool` in `go/bobtk/core/work_pool.go` provides dynamic concurrency control, waitable job completions (`SubmitWaitable`), task cancellation context, and barrier synchronization (`Wait`) inspired by U++ `CoWork` and JUCE `ThreadPool`.
- **Parametric Audio Processors:** `HighPassFilterProcessor` and `PeakingEQProcessor` in `go/bobtk/media/audio_graph.go` implement high-pass and biquad peaking equalizer DSP filtering (`juce::dsp::IIR::Filter` parity).
- **StyleSheet Engine:** `StyleSheet` in `go/bobtk/visual/style.go` provides CSS rule parsing and selector styling matching (`QStyleSheet` parity).
- **Polyphonic Synthesizer Engine:** `Synthesizer` and `SynthVoice` in `go/bobtk/media/synth.go` provide polyphonic voice tracking, MIDI note to frequency synthesis, dynamic voice stealing, and audio buffer rendering (`juce::Synthesizer` parity).
- **Notification Center & Desktop Alerts:** `NotificationCenter` in `go/bobtk/system/notification.go` manages desktop alert dispatching, urgency priority levels, listener subscriptions, and history logging (`QSystemTrayIcon::showMessage` parity).
- **SpinBox Numeric Control:** `SpinBox` in `go/bobtk/visual/widgets.go` provides integer value bounded input with step increments (`StepUp`, `StepDown`) and value change notifications (`QSpinBox` parity).
- **WorkPool Drain Guarantee:** `WorkPool` in `go/bobtk/core/work_pool.go` safely drains remaining buffered tasks upon shutdown while closing the channel under mutex synchronization.
- **BenchmarkRunner Throughput Analysis:** `BenchmarkRunner` in `go/bobtk/tools/tools_pillar.go` records iteration counts, total and average latency, and operations per second.
- **Sysprof-Capture Fallback:** `meson.build` provides subproject wrap fallbacks and default configuration options for `sysprof-capture-4` ensuring clean configuration when sysprof is absent from host pkg-config.
- **ScrollBar Widget:** `ScrollBar` in `go/bobtk/visual/widgets.go` provides horizontal/vertical scrolling, page steps (`PageUp`, `PageDown`), bounds clamping, and change signals (`QScrollBar` parity).
- **Deployment Documentation:** `DEPLOY.md` provides instructions for running pre-flight diagnostic monitoring and building the repaired Meson build tree.
